Сучасна, модульна та безпечна банківська система **Bank Forma Tail**, написана на **C++20** з акцентом на чисту ООП архітектуру, криптографічний захист персональних даних та красивий **оконний графічний інтерфейс (Desktop GUI)** без командного рядка cmd!

---

## ✨ Особливості та інтерфейс

### 🎨 1. Красивий Графічний Інтерфейс (Desktop GUI)
- **Справжнє десктопне вікно (без вікна CMD)**: При запуску відкривається автономне графічне вікно з підтримкою перетягування, кастомного дизайну та плавної анімації.
- **Преміальна банківська картка**: Візуалізація картки **Bank Forma Tail Black Platinum** із золотим мікрочіпом, безконтактною оплатою (`•))) Contactless`), 16-значним номером, терміном дії та ім'ям власника.
- **Миттєве перемикання між акаунтами**: Зручне перемикання між клієнтами в один клік (`user1` / `user2`).
- **Модальні вікна операцій**: Стильні вікна для внесення коштів та миттєвих переказів з автоматичною валідацією.
- **Журнал транзакцій та квитанції**: Таблиця всіх операцій з кольоровими бейджами (`+` зелений для поповнень, `-` червоний для переказів) та можливістю завантаження офіційної виписки.

### 🛡️ 2. Безпека та криптографія
- **Хешування SHA-256**: Паролі клієнтів та адміністратора хешуються за стандартом **NIST FIPS 180-4 SHA-256**.
- **Контроль доступу**: Розділення ролей на клієнта та системного адміністратора.

### 💳 3. Банківські операції
- **IBAN та картки**: Автоматична генерація міжнародного номера рахунку **IBAN** (`UA...`) та **16-значного номера картки** (`4441-XXXX-XXXX-XXXX`).
- **Поповнення (Deposit)**: Миттєве зарахування через термінал або касу.
- **Зняття готівки (Withdrawal)**: Зняття через банкомат ATM Forma Tail.
- **Миттєві P2P перекази (Transfer)**: Атомарний переказ коштів між рахунками за номером картки, IBAN або логіном.
- **Офіційна виписка**: Експорт структурованої виписки у файл `.txt`.

### 💾 4. Збереження даних (JSON)
- Усі дані зберігаються у прозорому та структурованому файлі **JSON** (`data/bank_data.json`).
- Збереження відбувається автоматично після кожної операції.

## 🚀 Як скомпільувати та запустити

### Запуск у режимі Desktop GUI (В один клік):
Просто двічі клацніть файл:
```cmd
run.bat
```
Або скомпілюйте самостійно:
```cmd
build.bat
```
*(Скрипт `build.bat` автоматично скомпілює всі компоненти і **відразу відкриє красиве вікно GUI** без вікна cmd!).*
