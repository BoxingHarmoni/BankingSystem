[![Build](https://img.shields.io/badge/Build-Passing-brightgreen.svg)]()

Сучасна, модульна та безпечна банківська система, написана на **C++20** з акцентом на чисту ООП архітектуру, криптографічний захист персональних даних, стильний консольний термінальний інтерфейс (з візуалізацією банківської картки та чеків), а також веб-панеллю моніторингу.

---

## ✨ Особливості та можливості

### 🎨 1. Стильний Інтерфейс Користувача
- **Візуалізація пластикової банківської картки**: Відображення чіпу, безконтактної оплати (`•))) Contactless`), 16-значного номера, терміну дії та імені власника прямо в терміналі.
- **Фіскальні чеки (Receipts)**: Автоматичне формування та виведення на екран естетичного банківського чека після кожної транзакції (поповнення, зняття, переказ).
- **Плавна кольорова гама ANSI**: Підтримка сучасних ANSI-кольорових схем та рамок з округленими кутами (`╭─╮`, `╰─╯`).
- **Веб-панель (Web Dashboard)**: Вбудований адаптивний веб-інтерфейс у папці `web/index.html` з підтримкою Tailwind CSS та інтерактивного кабінету.

### 🛡️ 2. Безпека та криптографія
- **Хешування SHA-256**: Паролі клієнтів та адміністратора хешуються за стандартом **NIST FIPS 180-4 SHA-256** без використання важких сторонніх бібліотек.
- **Маскування паролів**: Введення пароля приховано за зірочками `*`.
- **Контроль доступу**: Розділення ролей на звичайного клієнта банку та системного адміністратора.

### 💳 3. Банківські операції
- **Генерація офіційних реквізитів**: 
  - Формування міжнародного номера банківського рахунку **IBAN** (`UA...`).
  - Генерація **16-значного номера платіжної картки** (`4441-XXXX-XXXX-XXXX`).
- **Поповнення (Deposit)**: Миттєве зарахування через термінал або касу.
- **Зняття готівки (Withdrawal)**: Зняття через банкомат з верифікацією залишку та блокування.
- **Миттєві P2P перекази (Transfer)**: Атомарне списання та нарахування коштів між клієнтами за IBAN, номером картки або логіном.
- **Повна історія операцій**: Журнал з фіксацією дати, часу, типу операції, суми, контрагента та залишку.
- **Офіційна виписка**: Експорт структурованої виписки у файл `.txt`.

### 👑 4. Панель адміністратора
- Перегляд усіх зареєстрованих рахунків та клієнтів.
- Моніторинг загального капіталу (резервів) банку в режимі реального часу.
- Швидкий пошук клієнта за будь-яким реквізитом (ПІБ, картка, IBAN, телефон, логін).
- Блокування та розблокування рахунків (Freeze / Unfreeze).
- Глобальний журнал аудиту всіх операцій банку.

### 💾 5. Збереження даних (Data Persistence)
- Дані зберігаються у прозорому та структурованому форматі **JSON** (`data/bank_data.json`).
- Збереження відбувається автоматично після кожної операції.

## 🔑 Тестові акаунти для швидкого старту

Система автоматично ініціалізує демонстраційні акаунти при першому запуску:

| Роль | Логін | Пароль | Початковий баланс | Власник рахунку |
| :--- | :--- | :--- | :--- | :--- |
| **Адміністратор** | `admin` | `admin123` | — | Головний Адміністратор Банку |
| **Клієнт 1** | `user1` | `1234` | 24 000.00 ₴ | Коваленко Олександр Сергійович |
| **Клієнт 2** | `user2` | `1234` | 16 250.50 ₴ | Мельник Марія Іванівна |

*(Також у будь-який момент можна відкрити новий рахунок через пункт «[2] Відкрити новий рахунок»).*

│   ├── BankService.cpp
│   ├── ConsoleUI.cpp

## 🚀 Як зібрати та запустити

### Спосіб 1: Через `run.bat` (Рекомендовано)
Двічі клацніть або виконайте у терміналі:
```cmd
run.bat
```
*(Скрипт перевірить наявність бінарного файлу, за потреби виконає компіляцію та запустить програму).*

---

### Спосіб 2: Компіляція через `g++` (MinGW)
```bash
g++ -std=c++20 -O2 -Wall -Iinclude src/Utils.cpp src/Transaction.cpp src/Account.cpp src/StorageManager.cpp src/BankService.cpp src/ConsoleUI.cpp src/main.cpp -o bin/BankingSystem.exe
```
Запуск:
```cmd
bin\BankingSystem.exe
```

---

### Спосіб 3: Запуск веб-інтерфейсу
Просто відкрийте файл `web/index.html` у будь-якому сучасному браузері (Chrome, Firefox, Edge).
